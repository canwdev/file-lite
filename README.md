- **Backend**: a single Go (Echo) server, shipped as one static binary with the UI embedded; every [configuration field](./docs/config.md) and its default is documented
- **Bundle size**: single artifact stays around **20MB** or less
- **Features**
  - Explorer: tabs and split view, list / grid, breadcrumbs, favourites, drives, hidden files, filter, per-path sort and layout
  - Files & folders: create, rename, move, copy, duplicate, delete, properties, per-extension default app
  - Transfers: drag & drop upload (files or folders), download, download a folder as ZIP; copy, move and delete are cancellable background tasks over the WebSocket ([design notes](./docs/design/async-file-operations-ws-design.md)), with progress and retry
  - Conflicts: replace, skip or keep both — per item or for the whole batch — and folders merge the way Windows Explorer does it
  - Previews: server-generated thumbnails — image previews, video first frames via ffmpeg, audio cover art ([architecture](./docs/design/thumbnails.md)) — cached in the browser
  - Media: image viewer with zoom and rotate, video player, music player with playlist, embedded covers and synced lyrics
  - Endless Gallery: a short-video-style vertical feed of the current folder, with collect and a thumbnail strip
  - Editors & viewers: text editor, HTML viewer
  - Integration: embed File Lite as an Open File picker through a short-lived `ticket` URL, without a password
  - Utilities: speed test, realtime text sync
  - UI: light / dark / system themes with colour palettes, reduce motion, fullscreen, wake lock, touch-friendly
  - Maintenance: install a new backend binary, restart or stop the server from the Development menu
- **Security**
  - Password login issues JWT session tokens with a 1-year expiry
  - Console URLs use a short-lived `ticket` login parameter with a 2-minute TTL; printing URLs again generates a new `ticket`
  - “Remember login status” supports persistent cookies or browser-session cookies
  - Optional IP ban after repeated failed logins
  - Configurable allowed root path scope
  - Optional [IP-range allowlist](./docs/ip-allowlist.md) (`allowedCIDRs`)
  - HTTPS including [self-signed certificates](./docs/ssl.md)
  - Login attempt rate limiting

## Installation

Download the archive for your platform from [GitHub Releases](https://github.com/canwdev/file-lite/releases), unzip it and run the binary.

```shell
# Example: Linux amd64
unzip file-lite-linux_amd64-v*.zip
cd linux_amd64
./file-lite-go
```

## Development

Use **Bun** for the frontend and **Go 1.20+** for the backend; build steps and `bun run build:all` are documented in [backend-go/README.md](backend-go/README.md).

```shell
# Backend: hot-reload dev server on port 3111
cd backend-go
bun i
bun run dev
```

```shell
# Frontend: Vite dev server on port 3110, proxies /api to the backend
cd frontend
bun i
bun run dev
```

```shell
# Package the current platform: builds the frontend, the Go binary and the release zip
cd backend-go
bun run build
```

The UI is covered by a Playwright sub-project that drives the built app in a real browser — [e2e/README.md](e2e/README.md), method and case screenshots in [frontend-ui-testing.md](./docs/design/frontend-ui-testing.md); the screenshots above come from `cd e2e && bun run docs:screenshots` and land in [docs/screenshots](./docs/screenshots).

## Configuration

- Config file path: `<cwd>/file-lite/config.json` (override the directory with `FILE_LITE_DATA_BASE_DIR`)
- If `password` is empty, File Lite generates a random password; when the config file already exists, the generated password is written back
- `jwtToken` is the JWT signing secret; when an existing config file has an empty value, it is generated and written back
- The console does not print JWTs or signing secrets; check the config file for the login password

# Plugins

- Put a web page into the `plugins/` directory in the data directory, Any web page will work. Refresh the page, and you can open it from Plugins in the global menu. To develop plugins, see [Development](https://github.com/canwdev/file-lite/docs/design/plugins.md#development).
  - Example: `plugins/hello.html`
  - Example: `plugins/world/index.html` and `plugins/world/manifest.json`
- The archives of plugins that have already been adapted are in [plugins-repo](https://github.com/canwdev/file-lite/plugins-repo). You can download them by yourself.

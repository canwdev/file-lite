## Prebuilt Plugins

[English](README.md) | [简体中文](README-cn.md)

Plugins in the repository that have already been adapted for the [File Lite plugin system](../docs/design/plugins.md).

1. The plugin archive is available in the **GitHub Release attachments/assets** of some releases. For example, `plugin-jspaint.7z` is available as a release asset in certain releases.
2. Extract it to the `plugins/` directory in the [data directory](../docs/config.md). After extraction, it should be `plugins/jspaint/index.html`.
3. Refresh the page to take effect.

## Currently Available Plugins

Click the link to download the plugin archive.

- [OnlyofficePersonal](https://github.com/canwdev/file-lite/releases/download/v1.5.1/plugin-OnlyofficePersonal-9.3.0.133-20261029.7z): OnlyOffice Personal plugin for viewing and editing office documents. Source: [fernfei/OnlyofficePersonal](https://github.com/fernfei/OnlyofficePersonal)
- [jspaint](https://github.com/canwdev/file-lite/releases/download/v1.5.0-pre.27/plugin-jspaint.7z): Recreation of Microsoft Paint for drawing and editing images. [jspaint](https://github.com/1j01/jspaint)
- [webamp-player](https://github.com/canwdev/file-lite/releases/download/v1.5.0-pre.27/plugin-webamp-player.7z): Re-implementation of [Winamp](https://en.wikipedia.org/wiki/Winamp) in HTML5 and JavaScript, featuring full skin support and playback capabilities.
- [markdown-viewer](https://github.com/canwdev/file-lite/releases/download/v1.5.0-pre.27/plugin-markdown-viewer.7z): A plugin for rendering and viewing Markdown documents, built on the [Marked](https://github.com/markedjs/marked) library.
- [monaco-editor](https://github.com/canwdev/file-lite/releases/download/v1.5.0-pre.27/plugin-monaco-editor.7z): A plugin that bundles the [Monaco](https://github.com/microsoft/monaco-editor) code editor used in VS Code.
- [boxed-wine](https://github.com/canwdev/file-lite/releases/download/v1.5.0-pre.26/boxed-wine.7z): A plugin that bundles a [Boxedwine](https://github.com/danoon2/Boxedwine) for running Windows applications (32-bit only). Experimental and not yet stable.

## Prebuilt Plugins

Plugins in the repository that have already been adapted for the [File Lite plugin system](../docs/design/plugins.md).

1. The plugin archive is available in the **GitHub Release attachments/assets** of some releases. For example, `plugin-jspaint.7z` is available as a release asset in certain releases.
2. Extract it to the `plugins/` directory in the [data directory](../docs/config.md). After extraction, it should be `plugins/jspaint/index.html`.
3. Refresh the page to take effect.

`index.json` is generated by `node generate.mjs`; run `node generate.mjs --readme` to regenerate the list below from `index.json` and `download.json`. Edit those files instead of the list.

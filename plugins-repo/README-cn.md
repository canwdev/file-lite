## 预构建插件

本仓库中的以下插件已适配 [File Lite 插件系统](../docs/design/plugins.md)。

1. 插件压缩包可在部分 Release 的 **GitHub Release 附件/资源** 中获取。例如，某些 Release 中提供 `plugin-jspaint.7z` 作为发布资源。
2. 将其解压到[数据目录](../docs/config.md)下的 `plugins/` 目录。解压后路径应为 `plugins/jspaint/index.html`。
3. 刷新页面即可生效。

## 当前可用插件

点击链接下载插件压缩包。

- [OnlyofficePersonal](https://github.com/canwdev/file-lite/releases/download/v1.5.1/plugin-OnlyofficePersonal-9.3.0.133-20261029.7z)：用于查看和编辑 Office 文档的 OnlyOffice Personal 插件。来源：[fernfei/OnlyofficePersonal](https://github.com/fernfei/OnlyofficePersonal)
- [jspaint](https://github.com/canwdev/file-lite/releases/download/v1.5.0-pre.27/plugin-jspaint.7z)：Microsoft Paint 的复刻版，用于绘制和编辑图片。[jspaint](https://github.com/1j01/jspaint)
- [webamp-player](https://github.com/canwdev/file-lite/releases/download/v1.5.0-pre.27/plugin-webamp-player.7z)：使用 HTML5 和 JavaScript 重新实现的 [Winamp](https://en.wikipedia.org/wiki/Winamp)，支持完整皮肤和播放功能。
- [markdown-viewer](https://github.com/canwdev/file-lite/releases/download/v1.5.0-pre.27/plugin-markdown-viewer.7z)：基于 [Marked](https://github.com/markedjs/marked) 库构建的 Markdown 文档渲染与查看插件。
- [monaco-editor](https://github.com/canwdev/file-lite/releases/download/v1.5.0-pre.27/plugin-monaco-editor.7z)：打包了 VS Code 所用 [Monaco](https://github.com/microsoft/monaco-editor) 代码编辑器的插件。
- [boxed-wine](https://github.com/canwdev/file-lite/releases/download/v1.5.0-pre.26/boxed-wine.7z)：打包了 [Boxedwine](https://github.com/danoon2/Boxedwine)，用于运行 Windows 应用程序 (32-bit only)。实验性功能，尚不稳定。
